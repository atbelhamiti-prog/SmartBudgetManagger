# SmartBudget Manager README



SmartBudget Manager is a small Excel workbook for recording monthly income and expenses. Use it to see how much was spent, how the spending is divided by category, and whether the planned budget has been exceeded.

## What you need

Microsoft Excel 2016 or later, Microsoft 365, or a compatible spreadsheet application. Enable editing if the file opens in Protected View.

## Get started

1. Save a working copy of SmartBudget_Manager.xlsx. 2. Open Transactions. Add one transaction per row, using the Income or Expense type. Fill in the matching amount column. 3. Type the category name as shown on Categories. 4. Set category budget amounts on Categories. 5. Review Dashboard for totals, remaining budget, status, and the chart.

## A few things to know

The Month column is calculated; do not type over it. Dashboard totals include all transaction rows, so keep one month per workbook. Category names are typed manually. The workbook contains sample September entries; replace or clear them before tracking your own transactions.

## Saving and support

Save regularly with Ctrl+S (Windows) or Command+S (Mac). Keep an untouched backup of the original workbook. For help, contact your course instructor or the person who provided the workbook.
